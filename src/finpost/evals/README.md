# finpost.evals

Exact-answer evaluation for FinPost experiments. Runs one or more checkpoints on a benchmark split using greedy decoding and deterministic answer parsing, then writes five output files per run.

---

## Output Files

### `accuracy_summary.json` / `accuracy_summary.csv`

One row per (checkpoint, source) pair.

| Field | Type | Description |
|---|---|---|
| `checkpoint` | str | Checkpoint name supplied by the caller (e.g. `"base"`) |
| `source` | str | Eval source name (`"finchain"`) |
| `n` | int | Number of examples evaluated |
| `accuracy` | float | Fraction of examples scored correct |
| `parse_success_rate` | float | Fraction where the parser extracted a scoreable answer |
| `generated_tokens` | int | Total token positions generated (including pad fill) — use as compute denominator |
| `generated_tokens_decoded` | int | Non-pad tokens only — use for content-length metrics |
| `elapsed_sec` | float | Wall-clock seconds for this source |

### `details_<checkpoint>_<source>.csv`

One row per evaluated example.

| Field | Type | Description |
|---|---|---|
| `example_id` | str | Source-assigned identifier |
| `prompt` | str | Full prompt sent to the model |
| `generated` | str | Raw text generated by the model |
| `gold_answer` | str | Ground-truth answer |
| `predicted_answer` | str | Answer extracted from generated text (empty if parse failed) |
| `parse_success` | bool | Whether the parser extracted an answer |
| `is_correct` | bool | Whether `predicted_answer` matches `gold_answer` |

### `run_metadata.json`

Reproducibility record for the run.

| Field | Type | Description |
|---|---|---|
| `device` | str | Hardware name, e.g. `"Tesla T4"` |
| `dtype` | str | Torch dtype, e.g. `"torch.bfloat16"` |
| `torch_version` | str | PyTorch version |
| `transformers_version` | str | Transformers version |
| `cuda_version` | str | CUDA version, or `"N/A"` on CPU |
| `seed` | int | The `--seed` value |
| `eval_n` | int | The `--n` value |
| `git_sha` | str | Short git SHA of the code that ran the eval |
| `generation_settings` | dict | Per-source `{max_new_tokens, batch_size, do_sample}` |
| `checkpoints` | dict | Map of `{name: path}` supplied via `--checkpoints` |

### `cost_summary.json`

Timing and throughput record.

| Field | Type | Description |
|---|---|---|
| `run_name` | str | Final component of `--out-dir` |
| `start_time` | str | ISO-8601 timestamp when the run started |
| `end_time` | str | ISO-8601 timestamp when the run ended |
| `elapsed_sec` | float | Wall-clock total including model load and I/O |
| `generation_seconds` | float | Time inside `model.generate()` only |
| `gpu_type` | str | GPU name |
| `dtype` | str | Torch dtype string |
| `generated_tokens` | int | Total token positions across all sources and checkpoints |
| `generated_tokens_decoded` | int | Total non-pad tokens across all sources and checkpoints |
| `tokens_per_second` | float | `generated_tokens / generation_seconds` |
| `estimated_cost_usd` | float or null | Dollar cost if `--gpu-cost-per-hour` was supplied |

## CLI

```
python -m finpost.evals.eval_exact \
    --checkpoints NAME=PATH [NAME=PATH ...] \
    --sources SOURCE [SOURCE ...] \
    --n N \
    [--seed SEED] \
    --out-dir DIR \
    [--device {cuda,cpu}] \
    [--gpu-cost-per-hour USD] \
    [--batch-size-finchain N]
```

**Smoke test (tiny model on CPU):**

```bash
python -m finpost.evals.eval_exact \
    --checkpoints tiny=sshleifer/tiny-gpt2 \
    --sources finchain --n 4 --seed 42 \
    --out-dir results/evals/smoke \
    --batch-size-finchain 2 --device cpu
```

**Notes:**
- Each `PATH` must be an HF Hub model ID or a local directory in HF format (`config.json` + tokenizer files).
- `--device` defaults to `cuda` if available, else `cpu`.
- The CLI loads one checkpoint at a time — peak GPU memory is one model.
