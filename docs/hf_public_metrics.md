# Public HF Metrics Snapshot

Checked on 2026-06-02 from public files under `https://huggingface.co/shannan-liu1`. Percentages are exact-answer accuracy on the FinChain v2 template-disjoint test split unless noted. Compact local copies are also in `results/public_evals/`.

The GRPO/RLVR HF and eval paths retain the original upload label. Current configs and notebooks use the simpler `grpo` naming.

**Metric notes:**
- **Exact accuracy** — primary task metric; fraction of test rows with a correct final answer
- **Parse success** — fraction of rows where the answer parser extracted a scoreable answer (separates formatting failures from reasoning failures)
- **Step F1** — ChainEval harmonic mean of step precision and recall against the gold reasoning trace; a reasoning-shape diagnostic, not final-answer correctness

**DPO note:** the DPO pairs were built from the SFT model before a data fix affecting 10 training rows from one template. Validation and test splits contain zero rows from that template, so the held-out result is valid. The result stands as a negative result: DPO underperformed when pairs were generated by a weak policy.

**OPD/GKD note:** public selection metadata records `selection_status=did_not_beat_sft` for the validation promotion gate and leaves `test_touched_before_selection` null. The final held-out test accuracy is the highest in this snapshot, but the incomplete selection trace means this should be read as mixed evidence. The verified public repo is `shannan-liu1/qwen25-1p5b-finchain-v2-gkd-selected`.
