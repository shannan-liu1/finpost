## Known Limitations

- **OPD/GKD selection trace incomplete:** the public selection metadata leaves `test_touched_before_selection` null. The held-out test accuracy (19.43%) is the highest in this snapshot but should be read alongside that caveat.
- **Full notebook re-execution not done in clean repo:** smoke checks confirm notebooks compile; they do not confirm end-to-end training output matches reported numbers.
- **GRPO sparse reward risk:** verifier rewards collapse if the base policy rarely produces correct samples. This was monitored but not fully resolved at small model scale.

## Follow-Up

The most actionable next experiment is a DPO re-run with preference pairs generated by a stronger teacher model (the same setup that made OPD/GKD the best performer here). The current negative DPO result is likely a pair quality problem, not a fundamental DPO failure.
