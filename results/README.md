# Results

Only compact public metadata is committed here. Full training artifacts stay local or on Hugging Face.

**Committed:**
- `preflight/` — dataset provenance, split audit, checksums, and notebook smoke check
- `public_evals/` — aggregate accuracy, selection, and cost summaries per method

**Not committed:**
- Checkpoints and model weights
- Full per-example eval dumps
- Logs and cache directories
